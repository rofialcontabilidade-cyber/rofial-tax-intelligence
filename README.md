# RTI - Rofial Tax Intelligence

Sistema profissional de Planejamento Tributário para escritórios de contabilidade.

## Objetivo

O RTI permitirá comparar automaticamente:

- Simples Nacional
- Lucro Presumido

Além disso, o sistema realizará:

- Análise do Fator R
- Cálculo do Pró-labore Ideal
- Comparativo Tributário
- Planejamento Tributário
- Parecer Tributário Inteligente
- Simulações de Cenários
- Relatórios em PDF

## Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL
- Supabase
